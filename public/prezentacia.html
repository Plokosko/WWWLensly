Motivácia

Súčasný digitálny svet generuje obrovské množstvo vizuálnych dát. Tradičné prehliadače sú často len pasívnymi nástrojmi.

"Cieľom bolo vytvoriť komplexný systém, ktorý spája vysoký výkon .NET s modernými algoritmami AI pre autonómnu správu fotografií."

01 Inteligentná správa

Automatická kategorizácia a detekcia osôb v reálnom čase.

02 Natívny výkon

Využitie GPU akcelerácie Apple Silicon a frameworku Core Image.

03 Súkromie

Všetky biometrické dáta sú spracovávané a ukladané výhradne lokálne.

AI Proces

1.

Detekcia

Apple Vision lokalizuje tváre na fotografii.

2.

Zarovnanie

Normalizácia polohy očí a rotácie tváre.

3.

Embedding

ArcFace vygeneruje 512-rozmerný vektor.

4.

Klastrovanie

DBSCAN zoskupí tváre do identít (osôb).

Algoritmus DBSCAN

  • • Autonómne určenie počtu osôb
  • • Odolnosť voči šumu (neznáme tváre)
  • • Uhlová (kosinusová) podobnosť vektorov
// Clustering logic
var clusters = DBSCAN.Process(embeddings, eps: 0.5, minPts: 3);

@_cdecl("Lensly_ApplyEdit")
public func Lensly_ApplyEdit(...) -> Bool {
let ciImage = CIImage(contentsOf: url)
let filter = CIFilter.colorControls()
filter.inputImage = ciImage
return saveToDisk(filter.outputImage)
}
